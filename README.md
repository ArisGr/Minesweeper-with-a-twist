# Minesweeper-with-a-twist

This project is a JavaFX implementation of a custom **Minesweeper** variation, developed as a university assignment. The game extends the classic rules with additional mechanics such as a countdown timer and a unique “super-mine” that adds new strategic challenges. It supports different difficulty levels, customizable scenarios loaded from files, and a GUI that allows players to reveal tiles, mark suspected mines, and track their progress. Overall, it combines traditional gameplay with new twists to create a more dynamic and challenging version of Minesweeper.
